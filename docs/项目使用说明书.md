# Solana Paid Counter 项目使用说明书

## 项目简介

这是一个仅部署于 Solana devnet 的付费计数器。每个钱包拥有独立 Counter PDA；初始化、加一和减一每次支付 `0.001 SOL` 到 Vault PDA。第一个在 dapp 中成功设置 owner 的钱包成为不可变 owner，并可提取超过租金豁免余额的费用。

当前部署尚未调用 `set_owner`，Config 与 Vault PDA 尚未创建，首次设置留给 Playground 用户。

## 环境、安装与本地启动

需要 Rust、Solana CLI/cargo-build-sbf、Node.js 及 npm。不要把钱包 keypair、助记词或 token 写入仓库。

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:3000`。默认连接 devnet；可通过 `.env.local` 覆盖公开配置：

```dotenv
NEXT_PUBLIC_SOLANA_RPC_URL=https://api.devnet.solana.com
NEXT_PUBLIC_COUNTER_PROGRAM_ID=cFf5Vzhasx99wtJ3x9ivnGYYfoinwRtN6JjxyvtNJr9
```

钱包必须切换到 devnet，并预留账户租金、业务费用和网络费。每笔交易在请求钱包签名前由页面先模拟。

## 页面操作

1. 连接支持 Solana Wallet Standard 的钱包。
2. 若页面显示 owner 尚未设置，可点击设置 owner。该操作同时创建 Config 与 Vault PDA，且不可撤销或更换 owner。
3. 点击创建计数器，为当前钱包创建 Counter PDA；该操作收费 `0.001 SOL`。
4. 使用加一或减一修改计数器，每次收费 `0.001 SOL`。
5. 只有当前钱包是 owner 时，才可点击提取全部费用；程序会保留 Vault 的租金豁免余额。
6. 成功后通过页面交易链接在 Solana Explorer（devnet）确认。

所有 tag、参数和账户顺序见 `docs/ABI.md`。TypeScript 调用实现位于 `lib/counter.ts`，可直接作为命令行脚本或其他客户端的编码参考。

## 测试、构建与部署

```bash
cargo fmt --check
cargo clippy --manifest-path programs/paid-counter/Cargo.toml --all-targets -- -D warnings
cargo test --manifest-path programs/paid-counter/Cargo.toml
npm run test
npm run typecheck
npm run lint
npm run build
NO_DNA=1 cargo build-sbf --manifest-path programs/paid-counter/Cargo.toml
solana program deploy target/deploy/paid_counter.so --program-id target/deploy/paid_counter-keypair.json --url https://api.devnet.solana.com --commitment confirmed
```

部署前必须确认 `solana config get` 指向 devnet、`solana address` 可读取且 `solana balance` 足够。program keypair 位于被 git 忽略的 `target/` 内，不得提交或披露。重新生成 keypair 时必须同步更新 Rust `ID` 字节和前端默认 Program ID，再重新构建。禁止部署到 mainnet-beta。

## 常见问题与安全注意事项

- `AccountNotFound`（Config/Vault）：首次 owner 尚未设置时属正常；先由预期 owner 调用一次设置 owner。
- `AccountAlreadyInitialized`：owner 或 Counter 已设置，不能重复初始化。
- `InvalidSeeds` / `InvalidAccountData`：客户端 Program ID、PDA、账户顺序或账户 owner 不匹配。
- `Unauthorized`：当前钱包不是 Counter authority 或全局 owner。
- 模拟失败：检查 devnet 网络、钱包余额、Program ID、PDA 状态与 RPC 可用性；模拟成功前页面不会请求签名。
- owner 设置是“首个成功调用者生效”且不可变；在可信页面连接预期钱包后立即完成首次设置，避免被其他地址抢先初始化。
- 仅使用 devnet 测试 SOL，不要在本项目中使用主网资产或提交任何私钥。
